| Role | Family | Weight |
|---|---|---|
| `title` | Geist, system-ui, sans-serif | 600 |
| `node-name` | Geist, system-ui, sans-serif | 500 |
| `sublabel` | Geist Mono, ui-monospace, monospace | 400 |

The portable SVG requests no external fonts and uses the platform sans-serif fallback when Geist is unavailable. The HTML is the editable source; hero.svg is its extracted figure. The curriculum timeline is ordinal: equal intervals denote sequential course units, not elapsed time.
